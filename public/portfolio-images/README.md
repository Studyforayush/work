# Portfolio Images Guide

Add your 6 portfolio images to this folder with these exact filenames:

## Image Files Required:

1. **01-ai-genesis.jpg** - Golden temple with figure (Title: AI GENESIS)
2. **02-consciousness-rising.jpg** - Blue armored figure (Title: CONSCIOUSNESS RISING)
3. **03-neon-future.jpg** - Cyberpunk neon city (Title: NEON FUTURE)
4. **04-sacred-tech.jpg** - Robot in cathedral (Title: SACRED TECH)
5. **05-digital-apocalypse.jpg** - Destroyed golden city (Title: DIGITAL APOCALYPSE)
6. **06-genesis-awakening.jpg** - Another futuristic scene (Title: GENESIS AWAKENING)

## How to Add Images:

1. Copy your 6 images to this folder (`public/portfolio-images/`)
2. Rename them according to the filenames above
3. Make sure they are JPG or PNG format
4. Recommended image dimensions: 1400x1000px minimum

## Image Details:

Each image will automatically display with:
- **Smooth auto-sliding** every 6 seconds
- **Beautiful gradient overlays** for better text readability
- **Location titles** and **descriptions**
- **Tag information**
- **Counter showing** which slide you're on

The carousel is already configured and ready to use!
